> A luxury, high-performance web application and real-time appointment slot booking system designed for **Jugnu's Salon** (New City Phase 2 Arcade, Wah Cantt).

---

## 🌟 Key Features

- **💎 Luxury Dark Obsidian Design System**: Built with modern CSS custom properties, glassmorphic cards, glowing gold accents, and Google Fonts (`Playfair Display` + `Outfit`).
- **📅 Interactive Live Date & Time Slot Engine**:
  - Filter by category: Hair Care, Makeup Artistry, Skin & Facials, Royal Barat & Walima Bridal Packages.
  - Interactive Date Picker with automatic past-date blocking.
  - Real-time time slot availability matrix (Morning, Afternoon, Evening) with live status indicators (`Available`, `Limited`, `Booked`).
- **📱 Instant WhatsApp Booking Receipt**:
  - Generates a unique reference ticket (e.g. `JUG-8492`).
  - Pre-fills a formatted WhatsApp confirmation message sent directly to salon management (`0332-9555522`).
- **🛠️ Staff Portal / Admin View**:
  - Built-in staff manager tool (`Staff View` modal in header) to inspect customer appointments, delete bookings, or clear local storage slots.
- **📱 Fully Responsive**: Optimized for mobile screens, tablets, and high-DPI desktop displays.

## 🚀 Quick Start & Local Preview

No heavy node dependencies required! You can open and test the site locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/rehmanawais9/jugnu-salon.git
   ```
2. Open `index.html` directly in your browser, or serve using Python:
   ```bash
   python -m http.server 8080
   ```
3. Visit `http://localhost:8080` in your browser.
